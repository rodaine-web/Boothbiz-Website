# BoothBiz.io — Approved Landing Page Implementation

A responsive static marketing site based on the supplied BoothBiz SaaS Landing Page Showcase design.

## Preview
Open `index.html` in a modern browser. For best results, serve the folder from a static web server (e.g. `python3 -m http.server 8000`). No build step or external dependencies are required.

## Implemented
- BoothBiz Lens B branding and approved purple/blue palette.
- Hero with the BoothBiz owner dashboard laptop image (no smartphone overlay).
- Six feature categories with scalable inline SVG icons.
- Eight product-tour tabs in this order: Dashboard, Reports & Analytics, Leads, Proposals, Campaigns, Calendar, Events, Gallery. Each uses a standardized laptop frame; Events and Gallery are newly created illustrative previews.
- Two angled Connect Page smartphone mockups, built with HTML/CSS.
- Styled integration partner wordmarks; these are typographic approximations, not official trademark assets. Replace with licensed official SVG logos before launch.
- Annual-first pricing with functioning monthly toggle ($29/$69/$129 annually billed; $39/$89/$169 monthly).
- A workflow-benefits section in place of unverified customer testimonials.
- Prelaunch waitlist form, CTA banner, polished multi-column footer and social links.
- Responsive desktop/tablet/mobile layout and accessible product tour controls.

## Launch checklist
1. Waitlist currently opens a prefilled email to `hello@boothbiz.io`. It does **not** persist submissions. Connect a real waitlist backend before launch.
2. Confirm `hello@boothbiz.io` exists.
3. Confirm Instagram, LinkedIn, TikTok and Snapchat profile URLs; they are proposed and unverified.
4. Integrations are proposed and may not all be available at launch.
5. Product screenshots are illustrative BoothBiz-branded concept mockups based on LOLA Admin workflows, not captures from a live multi-tenant product.
6. Publish proper Privacy Policy and Terms of Service pages before launch.
7. Pricing and plan features are proposals subject to change.
