# BoothBiz public marketing website

Approved marketing redesign published independently of Lola and BoothBiz product staging. Static HTML/CSS/JavaScript; no build step. Includes an eight-screen illustrative product tour and a four-step questionnaire preview. Pricing cards are omitted.

## Current release limitation
Early-access registration is not open. Submission is disabled and the page clearly explains that answers are not sent or saved. Identity and long-form personal information fields are disabled. No production request is routed to BoothBiz staging.

## Deployment
Existing Vercel project boothbiz-website; existing boothbiz.io/www.boothbiz.io domains. Preserve staging in its separate private repository/project. Never deploy product source or provider credentials here.

## Follow-up
Enable a dedicated production waitlist service only after verified persistence, consent/privacy/contact/retention details and end-to-end acceptance. Remove the preview-only limitations only after that release.
